# Changelog

Every Compass release, newest first. The app shows the same list under Settings › Changelog.

## 1.15.1 · 2026-11-16

- Fix: 1.15.0 could empty your library list the first time it started. If yours is empty, Compass offers to restore the copy from before the update (your audio and covers were never touched). Settings › Backup › Find an older copy does the same any time.

## 1.15.0 · 2026-11-16

- Verified albums: digital albums from the Store, the Marketplace, a QR card or your own Publish carry a green verified seal. Albums you add from files are Local. Everything already in your Digital albums is verified.
- Digital albums: filter All, Verified or Local.
- Music Store: sxteen ways – Movie is free. Get adds a verified copy to your library; the QR card gives the same album.

## 1.14.1 · 2026-11-16

- CD Creator: new CD100 template set (CD100 booklet, CDT100 tray card, UD100 disc). Guides follow the printer’s templates: bleed, trim, safety, spine folds, the spine window inside the tray card, and the disc’s print rings. Print files use ⅛ in bleed and a full 122 mm disc square.
- New CDs use the CD100 set. Existing CDs stay on Classic; switch any CD under Template in the side panel.
- Rolled back the 1.14.0 case look.

## 1.14.0 · 2026-11-16

- CD case look updated (rolled back in 1.14.1).

## 1.13.9 · 2026-11-16

- Store pages: right-clicking the CD case no longer opens the CD Creator’s editing menu.
- Convert: YouTube links work again. Compass gives the link tool its own built-in JavaScript runtime (YouTube now requires one), keeps the tool up to date weekly, and shows the real error instead of a warning.

## 1.13.8 · 2026-11-16

- Project pages are tighter so a full album fits on one screen without scrolling.
- Artists: a song counts for the artist in its own Artist field, then the one in an "Artist - Song" title, and only then the project’s artist (folders don’t count). A song titled "Travis Scott - …" no longer counts as Latto just because it sits in a Latto project.
- Artist page: All N songs shows every song counted for that artist, so you can check and fix them.

## 1.13.7 · 2026-11-16

- Reordering songs only animates the disc you’re moving them on; the other discs stay still.

## 1.13.6 · 2026-11-16

## 1.13.0 · 2026-11-16

- Publish: when every song is Final, Publish copies the project into a digital album and opens its Store settings: price (free is fine), number of copies or unlimited, CD and CD-upgrade prices, description, resale rules and wholesale packs. Your project stays editable.

- Marketplace: Wholesale code packs (500, 1500, 5000, 10000) for shops and vendors. Each pack downloads as a CSV plus printable QR cards; every code works once and counts toward a limited edition.

## 1.9.0 · 2026-11-14

- Mods: put mods in Documents › Compass › Mods and turn them on in Settings › Mods. A mod can restyle the app and add song or project menu items, react to what is playing, and control the player. It runs in a sandbox and can never touch the Music Store or Marketplace. Open the folder once to get an example mod.
- Launcher: right-click a DAW to pick which installed version to open (for example FL Studio 21 or 2024). Open remembers the one you picked.
- FL Studio screen redesigned: one row of tabs (Recent, All projects, Zipped loops, Backups), one toolbar (search, sort, and a folder filter only when you have more than one folder), and a compact one-line list. Folders and the backup folder are managed from one Folders button. Right-click a project to show it in its folder.
- Backups tab: FL Studio's own autosaves (Projects › Backup), or a backup folder you choose.
- Features: a small button next to Details & credits. Type @ and a name to tag an artist. Each one can be in the title (feat.), under the title, or not named. Their info (legal name, role, PRO, IPI, publisher, publishing email) is saved once and fills in on every song you feature them on. Nothing is required.
- Deleting a version asks first.
- Previous restarts the song when you are more than 3 seconds in. On the first song it restarts that song instead of jumping to the end (unless Repeat all is on).
- Song panel is shorter: tags, features, the preview and the project checklist are gone (features live in Details & credits; Add to / Move to are in the song menu). Status, BPM and key sit on one row.
- Export song info: one song from its panel (Export info), or every song in a project from Share & export (Export song info). Saves a .txt with credits, BPM, key, ISRC, lyrics and more.
- Cleaner, less cluttered app. Buttons that did the same thing are merged:
- Library: one Add music button (it takes .zip downloads too). Scan QR is a small icon. The sidebar footer is just credits and the version (click it to check for updates).
- Project page: the header is Play, Add songs, Share and ⋯. Rename and Edit details are one item. A song's ⋯ opens the same menu as right-click, starting with Edit song.
- CD Creator: one Export menu (print files, 3D model, picture). One Viewer button. Opacity, fill and text options each live in one place instead of two or three.
- Settings: Desktop app and About are one row. The EQ lives in the player bar only. CD Creator shortcuts are tucked under their own heading.
- Menus use the same capitalisation everywhere, and the nav icons are all different.
